# Instruction assistée des remboursements santé (IA)

Prototype d'instruction assistée des demandes de remboursement de complémentaire
santé, mené en MOA et en Agile Scrum. Données synthétiques uniquement.

## Objectif
Lire des documents de remboursement (factures, décomptes), en extraire les
informations par IA, contrôler leur cohérence et préparer le dossier pour un
gestionnaire, qui garde la décision finale.

## Statut
Sprint 0 : cadrage en cours (charte, glossaire, risques, cas de test).

## Structure
- docs/ : charte projet, glossaire, risques, backlog
- samples/ : documents fictifs de test
- src/ : code (à venir)

## Avertissement
Aucune donnée réelle de santé. Ne jamais publier de clés AWS ni de données personnelles dans ce dépôt.

## Statut
Sprint 1 en cours : documents synthétiques (US-01) et extraction de champs (US-02) terminés.
Suivi réel dans Jira (accès sur demande).
