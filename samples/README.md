# Jeu de documents synthétiques

Tous les documents sont **fictifs** : noms, montants, organismes et références sont inventés.
Chaque document porte la mention « DOCUMENT FICTIF ».

- `TC-xx_*` : documents des 10 cas de test (voir `docs/cas-de-test.md`)
- `TC-05b_scan_net.png` : scan net du même document que TC-01 (contrôle de netteté, US-04)
- `contrat-fictif.json` : contrat de la complémentaire fictive (bénéficiaires, garanties)
- `resultats-attendus.json` : résultat attendu pour chaque cas (champs, calculs, alertes)

Ne jamais ajouter de document réel dans ce dossier.
